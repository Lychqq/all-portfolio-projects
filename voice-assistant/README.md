# Voice Assistant & Speech-to-Text Service

Учебный веб-сервис для локального захвата, сохранения и распознавания речи (Speech-to-Text). Разработан в рамках практики для отработки навыков построения REST API на FastAPI, работы с базой данных через SQLModel и интеграции со стриминговой записью аудио в браузере.

Проект предназначен для локального запуска и тестирования на машине разработчика.

---

## Технологический стек

### Backend
- **Python 3.11+**
- **FastAPI** — высокопроизводительный асинхронный веб-фреймворк для обработки запросов.
- **SQLModel / SQLite** — ORM для структурирования моделей данных и персистентного хранения истории транскрибаций.
- **SpeechRecognition & pydub** — обработка аудиофайлов (конвертация форматов, расчет таймингов и обращение к движку распознавания Google Speech API).
- **Uvicorn** — ASGI-сервер для запуска приложения.
- **aiofiles / python-multipart** — асинхронная работа с файловой системой и multipart/form-data.

### Frontend
- **Vanilla JavaScript (ES6+)** — логика записи и отправки без тяжелых фреймворков.
- **Web Audio API & MediaRecorder** — захват аудиопотока с микрофона пользователя в формате WAV/Blob.
- **Fetch API & FormData** — асинхронная передача бинарных аудиоданных на бэкенд.
- **CSS3 / Golos Text** — адаптивная верстка интерфейса с палитрой в серо-графитовых тонах.

## Архитектура и принцип работы

1. **Захват аудио:**
   - Через браузерный интерфейс пользователь может записать речь с микрофона в реальном времени с помощью `navigator.mediaDevices.getUserMedia()` и `MediaRecorder`.
   - Альтернативно поддерживается загрузка любого готового аудиофайла (WAV, MP3, OGG).
2. **Передача на сервер:**
   - Браузер упаковывает аудио-броб в объект `FormData` и отправляет POST-запрос на эндпоинт `/transcribe/`.
3. **Обработка и сохранение:**
   - FastAPI асинхронно сохраняет входящий файл в папку `uploads/`.
   - Модуль `ai_service.py` через `pydub` определяет длительность дорожки и конвертирует аудио в формат, пригодный для `speech_recognition`.
   - Движок распознает текст на русском языке.
   - Метаданные (название файла, путь, длительность, расшифрованный текст) записываются в локальную базу данных SQLite (`database.db`).
4. **Ответ клиенту:**
   - Сервер возвращает JSON с распознанным текстом и длительностью аудио, который сразу выводится в интерфейс.

## Эндпоинты API

- `GET /` — отдает главную страницу интерфейса.
- `POST /transcribe/` — принимает multipart/form-data файл `file`, сохраняет его на диск, транскрибирует аудио, сохраняет запись в БД и возвращает JSON вида:
  ```json
  {
    "text": "Распознанный текст сообщения",
    "long": 3.45
  }
  ```
- `GET /records/` — возвращает список всех сохраненных аудиозаписей и их транскрипций из базы данных.
- `GET /docs` — интерактивная OpenAPI/Swagger документация.

## Инструкция по локальному запуску

### 1. Клонирование и переход в директорию
```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd voice_assisten
```

### 2. Создание и активация виртуального окружения
```bash
# Windows
python -m venv .venv
.venv\Scripts\activate

# Linux / macOS
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Установка зависимостей
При использовании `uv`:
```bash
uv sync
```
Или стандартным `pip`:
```bash
pip install fastapi sqlmodel uvicorn python-multipart speechrecognition pydub aiofiles httpx
```

> **Примечание:** Для работы библиотеки `pydub` с нестандартными форматами аудио на машине может потребоваться установленный `ffmpeg` в системных переменных PATH.

### 4. Запуск сервера
```bash
uvicorn main:app --reload
```

После запуска приложение доступно по адресу:
- Веб-интерфейс: `http://127.0.0.1:8000/`
- Swagger UI: `http://127.0.0.1:8000/docs`
